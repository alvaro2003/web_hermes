# Hermes B2B

## Como instalar e rodar o projeto

### 1. Baixe o .zip no github

Baixe e deszipe o projeto do git hub
adicione a pasta principal do projeto dentro do arquivo deszipado no Visual Studio Code

### 2. Configure o backend

dentro de um terminal na pasta backend e rode:
npm install
npm start

### 3. Configure o frontend

Abra um novo terminal na pasta frontend e rode:

cd frontend
npm install
npm run dev

O site vai rodar em http://localhost:5173

## Como usar

Na página Estoque é possível visualizar todos os produtos cadastrados.
Na página Gerenciar é possível adicionar um novo produto informando nome, quantidade, data de validade, data de entrada e localização. Também é possível remover um produto pelo seu ID.
